# AMM 巡检报告归档

本目录存放 AMM 项目例行巡检（cron: `amm-project-progress`，每 15 分钟）自动生成的巡检报告。

## 存放位置

- **巡检报告统一归档目录**：`patrol-reports/`（本目录）
- 命名规范：`巡检报告_YYYYMMDD_HHMM.md`（如 `巡检报告_20260808_1243.md`）
- 早期散落在仓库根目录的报告已统一移入本目录归档。

## 报告内容

每份报告包含：Git 进度推送情况、近 15 分钟变更、健康状态（进程/日志/负载/磁盘/内存）、模型与验证状态、自动修复动作、下一步计划。

## Gitea 上的位置

仓库内网 Gitea：`iei/amm`，路径 `patrol-reports/`。
推送地址：`http://192.168.100.245:60005/iei/amm.git`

> 巡检任务 cron 生成报告时写入本目录，随后随 `git add -A` 提交并推送 Gitea，保持巡检报告持续归档。

## 归档策略

- 巡检报告持续追加到本目录，不覆盖，便于回溯历史。
- 可按需按日期/版本子目录归档，但为保持 cron 简单，当前统一平铺存放。

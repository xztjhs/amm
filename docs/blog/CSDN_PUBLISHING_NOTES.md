# CSDN 发布注意事项（配合 amm-intro-csdn.md 使用）

## 一、GEO 搜索优化建议

1. **标题含关键词**：已用「AI 模型统一调度平台 + llama.cpp/vLLM/Diffusers」，把核心搜索词放在前面。
2. **首段点题**：已把「什么是 AMM、解决什么问题」放在文章开头，符合搜索收录抓取习惯。
3. **多级标题 + 关键词布局**：`混合推理引擎架构`、`OpenAI 兼容 API`、`FP8 量化`、`显存`、`9 类模型` 等高频词已在 H2/H3 中出现。
4. **代码块与表格**：CSDN 对结构化内容收录权重更高，表格已用于特性/矩阵对比。
5. **标签**：发布时建议选 4~5 个标签，如：
   - `llama.cpp`
   - `vLLM`
   - `机器学习`
   - `深度学习`
   - `大模型`
6. **文末站内/外链接**：指向 GitHub https://github.com/xztjhs/amm，利于收录关联。

## 二、广告审核规避要点（重要）

CSDN 对涉商/引流内容会拦截，务必注意：

1. **已规避的表述**：
   - ❌ 不用「最强 / 第一 / 碾压 / 完美 / 天花板」等绝对化夸大词 ✓（本文未使用）
   - ❌ 不写价格、促销、付费链接 ✓
   - ✅ 全文定位为「开源技术交流」，结尾已加「不构成任何商业建议」
2. **请勿做**：
   - 在文章里加微信号 / 公众号 / 二维码 / 商务合作联系方式
   - 把 URL 大量重复堆砌（会被判 SEO 垃圾）
   - 标题用「震惊 / 必收藏 / 免费送」等营销词
3. **如果被审核驳回**：通常是因为含外链或疑似引流。处理方式：
   - 把 GitHub 链接改成纯文本或在「参考资料」区只保留一次
   - 去掉结尾的引导性质语句（如「点个 Star / 欢迎交流」可保留但别反复强调）
   - 检查是否有「优惠 / 限时 / 免费领取」字样
4. **原创声明**：发布时勾选「原创」，可申请 CSDN 原创标识，利于同领域推荐。

## 三、发布操作

1. 在 CSDN 编辑器粘贴 `amm-intro-csdn.md` 内容（Markdown 源码）。
2. 填题、选分类（人工智能 / 深度学习）、加标签、选「原创」。
3. 插入 1~2 张架构图可提升可读性（可用文章里的 ASCII 架构图代码块转成图片，或用 mermaid 画一张）。
4. 预览检查后发布。

> 提示：文章里 `Qwen3.6-35B` 等模型名为真实部署用名，若不想透露具体型号可改成「Qwen 系列」等通用说法（当前版本为真实信息，发布前请确认是否可公开）。

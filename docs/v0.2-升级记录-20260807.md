## 二、新增后端 API

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/fs/list?path=` | 浏览 /models 目录树（防穿越、任务级导航、工程父级） |
| GET | `/api/fs/discover?dir=&engine=` | 按引擎发现目录/文件 |
| GET | `/api/instances/preset?model_file=&engine=` | 查找/解析预设配置文件 |
| POST | `/api/instances/preset/apply` | 应用预设到实例参数 |
| POST | `/api/instances/preset/save` | 把参数保存为 `<model>.<engine>` |
| POST | `/api/settings/reload` | 热重载 models_config.yaml |
| POST | `/api/settings/restart` | 安全重载+实例刷新 |

新增后端模块：`backend/api/fs_bridge.py`

## 四、过程中的故障与修复

1. **浏览器缓存**：新增功能不生效（旧 app.js 被缓存）→ 加 `?v=0.2.1` 版本戳强制刷新
2. **`escapeHtml is not defined`**：误删 `escapeHtml` 定义导致 Models/Dashboard/Playground 空白
   → 恢复定义 + 用 headless Chrome CDP 逐页验证
3. **入口进程**：容器 PID1 由 `/usr/sbin/sshd -D` 改为 entrypoint 脚本启 sshd + 前台跑 server.py
4. **递归进程树清理**：vLLM EngineCore 子进程脱组残留 → `stop_process` 用 psutil+`/proc` 递归回收

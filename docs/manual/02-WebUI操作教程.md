# 第 2 章 AMM WebUI 操作教程（Step by Step）

> 版本：v1.9 ｜ 更新日期：2026-11-17
> 阅读前提：服务已启动，浏览器能打开 `http://<服务器IP>:<端口>/`

---

## 2.1 界面总览

顶部导航栏八个入口：

```
Dashboard │ Models │ Token Router │ Playground │ Tools │ Log Center │ GPU │ Settings
```

右上角常驻：

| 元素 | 作用 |
|---|---|
| 📚 手册 | 打开本用户手册 |
| 刷新间隔下拉 | 页面自动刷新频率（0.1s ~ 5min，默认 0.5s） |
| 🌙 / ☀️ | 浅色 / 深色主题切换（记忆偏好） |
| 状态点 | 绿=Online 红=Offline（服务是否可达） |
| 时钟 | 当前时间 |

> **刷新间隔建议**：日常用 2s 或 5s。0.1s 只用于观察瞬时指标，长期开会让日志增长很快。

## 2.2 Dashboard：先确认环境正常

打开首页，从上到下看三块：

### ① 四张系统卡
CPU / Memory / Disk 各有一条进度条，Uptime 显示服务运行时长。
进度条宽度 = 百分比数值，两者应当一致。

### ② GPU 状态
每张 GPU 一张卡，显示：

| 指标 | 含义 |
|---|---|
| 计算利用率 | GPU 核心忙闲程度 |
| 显存带宽 / 编码器 / 解码器 | 各子单元利用率 |
| 显存占用 | 已用 / 总量，如 `9832/24564 MB` |
| 温度 / 风扇 / 功耗 / SM 时钟 | 硬件状态 |
| 显存时钟 / PCIe | 链路状态 |
| 正在运行的程序 | 哪些进程占了显存，各占多少 |

> **排错提示**：模型启动后如果这里看不到对应进程，说明它没跑在 GPU 上（见第 8 章）。

### ③ Model Status
九个模型实例的列表：模型 / 类别 / 引擎 / 端口 / 状态 / 显存 / 运行时长 / 操作。
每行右侧有 Start / Stop / Restart 按钮，点模型名可打开详情弹窗（改参数、换模型文件、看日志）。

## 2.3 Models：启动第一个模型

点导航栏 **Models**，默认在「🚀 启动新实例」。

### 2.3.1 启动向导五步

**第 ① 步：选模型类别**
下拉里是九类模型。选 Embedding 做第一个实验最稳妥（0.6B 模型，几百 MB，秒级启动）。

**第 ② 步：选推理引擎**
选完类别后，这里只列出支持该类别的引擎。通常选 `llama.cpp`。

**第 ③ 步：选引擎版本 / Flavor**
下拉列出已安装的版本，形如 `b12381 · cuda`。
如果这里是空的，说明还没装引擎 → 去 **Settings → 推理引擎管理** 装。

**第 ④ 步：选模型文件**
两种方式：

- 点 **📂 浏览** 打开文件浏览器，逐级点进目录选文件
- 直接粘贴相对路径，如 `Qwen/Qwen3-Embedding-0.6B-GGUF/Qwen3-Embedding-0.6B-Q8_0.gguf`

> 路径都是相对 `/models` 的。文件浏览器里看到的目录树就是 `/models` 下的内容。

**第 ⑤ 步：填参数（可选）+ 实例名**

| 字段 | 说明 |
|---|---|
| **实例 UID** | 客户端看到的模型 ID。**强烈建议留空**，系统会按模型文件自动生成带类别的名字（如 `qwen3-embedding-0.6b`） |
| **模型名称** | 客户端显示的友好名称，留空也会自动生成 |
| 副本数 | 同一模型的并发副本数，一般填 1 |

> **UID 有个坑要注意**：如果你手填 `qwen3` 这种裸家族名，
> Cherry Studio 这类客户端会把它误认成 `Qwen3 14B` 聊天模型并丢掉 embedding 能力。
> 页面会实时用 ⚠ 提示你，照它的建议改即可。

下面的参数区由「类别 + 引擎」自动生成：
embedding 类别会自动带上 `embeddings=true`，reranker 带 `reranking=true`，不用手动勾。

**点 ▶ 启动**

启动成功后右上角提示 `实例 xxx 已启动（端口 18100）`。

### 2.3.2 运行中实例

切到「📦 运行中实例」子页。

顶部统计条：运行中数量 / 动态实例数 / 已占用端口 / GPU 显存合计。

列表每行的操作：

| 按钮 | 作用 |
|---|---|
| Start / Stop | 启动 / 停止（停止后端口仍预留） |
| Restart | 重启（参数变更后需要） |
| 详情（点模型名） | 打开弹窗：改参数、换模型文件、换引擎、看启动命令、看日志 |
| 💾 | 另存为模版 |
| 结束运行 | **停止并从实例列表移除**（释放端口，需二次确认） |

> **Stop 和 结束运行的区别**：Stop 只是停进程，实例定义还在，可再 Start；
> 「结束运行」会删除实例定义，端口回收给别的实例用。

### 2.3.3 模版库

切到「🗂 模版库」子页。预置了 14 个常用模型模版。

- 顶部可按分类过滤、按关键词搜索
- 点模版卡打开详情抽屉：引擎 / 下载源 / 部署表单
- **一键部署**：勾选引擎 → 填 UID（可留空）→ 点部署，直接创建实例
- **下载模型文件**：如果本地还没有模型文件，先点这个
- ＋新建模版 / ⧉ 复制 / ✏️ 编辑 / 🗑 删除（仅自定义模版可删）

## 2.4 Playground：在线测试

点导航栏 **Playground**，九个页签对应九类模型。

### Chat（对话）

1. **模型** 下拉选一个 running 的实例
2. 三个参数：Temperature（随机性，0.7 常用）、Max Tokens（最大生成长度）、Top-P（采样范围）
3. 可选 System Prompt（系统提示词）
4. 可选上传图片（视觉模型才能用）
5. 输入框输入问题，点 **Send** 或按 Enter（Shift+Enter 换行）

响应是流式的，逐字出现。右上角 **🗑 清空会话** 重置多轮上下文。

### Embedding（向量）

- 选模型
- 文本框里放要向量化的句子，**多条用 `|` 分隔**
- 点 **⏱ 测试 Embedding**

结果区显示向量维度、耗时、吞吐。默认三条测试句可直接点。

### 其他七个页签

| 页签 | 输入 | 输出 |
|---|---|---|
| ASR | 上传音频（wav/mp3） | 转写文字 |
| TTS | 输入文字 | 生成的语音 |
| Rerank | Query + 每行一个候选文档 | 相关性排序 |
| OCR | 上传含字图片 | 识别文字 |
| T2I | Prompt + 宽高/步数/引导/数量/种子 | 生成的图片 |
| T2V | Prompt + 分辨率/帧数/步数/引导 | 生成的视频 |
| I2V | 首帧图 + Prompt + 参数 | 生成的视频 |

> **T2V / I2V 很慢**：480P 一条通常 5–15 分钟，属正常。页面上会显示显存估算，
> 显存不够时建议降分辨率或减帧数。

## 2.5 Token Router：对外提供服务

如果你要让别的应用（Cherry Studio、自己的程序、Agent）调用 AMM，用这个页面。

### 2.5.1 接入外部 Provider（可选）

如果你还想通过 AMM 统一转发第三方 API（如 icompify、siliconflow）：

1. **名称**：唯一标识，如 `icompify`
2. **类型**：选 openai / anthropic / deepseek / icompify / custom
3. **Base URL**：留空用该类型的默认地址，或手填
4. **API Key**：粘贴 Key（也支持填环境变量名）
5. 点 **🔄 拉取模型** 自动获取可用模型列表
6. 点 **💾 保存 Provider**

> ⚠️ **一定要核对 Base URL**。曾出现过 Key 填了 icompify 但 Base URL 是
> `api.openai.com`，导致报错指向 OpenAI、极难排查。

### 2.5.2 签发虚拟 Key

如果你想让不同应用用不同的 Key、分别限额：

1. 填 **名称**（如 `my-app`）
2. **RPM 限制**：每分钟请求数，0 = 不限
3. **月度 Token 限额** / **总 Token 限额**：0 = 不限
4. **有效期至**：留空 = 永久
5. **可访问模型**：不勾选 = 允许全部
6. 点 **＋ 签发 Key**

> **明文只显示一次**，请立刻复制保存。列表里之后只显示掩码。

### 2.5.3 用量与计费

下半部分是按 Key 聚合的用量表（请求数 / 输入 / 输出 / 总 tokens / 金额），
以及按 Key 的平均性能指标（TTFT / ITL / TPOT / TPS / E2E）。

两个导出按钮：**📄 导出账单 CSV**、**📋 导出详单 CSV**（Excel 直接可开，带 BOM）。

## 2.6 Tools：下载与转换模型

### 2.6.1 模型自动下载

1. **下载源与网络**
   - HuggingFace 镜像：国内选 `hf-mirror.com`，国外选官方
   - HF API Key：只有私有/受限仓库才需要
   - HTTP 代理：可选
2. **选择模型**
   - 来源：ModelScope（国内优先）/ HuggingFace
   - 模型 ID：如 `Qwen/Qwen3-Embedding-0.6B-GGUF`
   - 目标目录：留空存到默认 zoo 快照，或填 `vllm/Qwen3-4B`
3. 点 **🔍 查询版本与文件** → 勾选需要的文件 → 点 **⬇️ 开始下载**

下载任务显示实时进度与速度，可取消。

### 2.6.2 GGUF 量化

选源文件 → 选量化类型（q4_k_m / q5_k_m / q8_0 / fp16…）→ 选输出目录 → 开始。
适合把 safetensors 或高精度 GGUF 压小。

### 2.6.3 vLLM → GGUF 转换

填源模型目录、量化方式、输出路径、输出名，点开始转换。

## 2.7 Log Center：看日志与调用记录

两个子页签。

### 文件日志
- 来源下拉：全部 / 服务日志 / 各模型日志
- 级别过滤：ALL / ERROR / WARNING / INFO / DEBUG / RAW
- 关键字过滤、显示行数
- **⬇️ 导出当前筛选** / **🗂 文件管理** / **🧹 清理**
- 自动刷新勾选框（5s 一次）

### 调用历史（重点）

按模型 / 来源 / 时间窗 / 关键字筛选，**点任意一行展开**详情：

| 面板 | 内容 |
|---|---|
| 输入 | 对话时的 messages 摘要（角色 + 内容） |
| 输出 | 模型实际生成的文本（流式也会记录真实内容） |
| 参数 | temperature / max_tokens / top_p |
| 性能 | e2e、ttft、itl、tpot、tps |

> v1.9 起，本地实例的 chat / embeddings / rerank 都会记录；
> 流式调用的「输出」不再是 `(stream)` 占位符。

## 2.9 Settings：配置与运维

### 2.9.1 服务配置（只读）
API Host / Port / Models Dir / Logs Dir / 版本号。

### 2.9.2 PyPI 镜像源
引擎安装时的 pip 下载走这个源。可以选国内镜像预设，也可以手填。改完点保存。

### 2.9.3 对外服务 API Key
- **🎲 随机生成**：生成一个默认 Key，之后客户端访问 `/v1/*` 必须带上
- **📋 复制** / **清除**
- 留空 = 内网免鉴权直连

### 2.9.4 鉴权开关（v1.9）
- 状态徽章显示当前是「鉴权已开启」还是「已关闭」
- **🔓 完全关闭鉴权**：二次确认（输入 YES），关闭后任何能访问端口的人都能调 `/v1/*`
- **🔒 重新开启鉴权**：恢复强制鉴权

> **为什么需要这个按钮**：签发过 Key 后，为避免旧 Key 持有者突然获得无鉴权访问，
> 系统会一直保持鉴权。想真正退回免鉴权，必须点这里。

### 2.9.5 客户端分组名
客户端 `/v1/models` 里的 `owned_by` 字段用它替代随机 UUID，方便在客户端里识别来源。

### 2.9.6 项目品牌（v1.9）
- **项目名称** / **副标题**：改完顶栏、浏览器标题栏立即同步
- **LOGO 路径**：默认 `/assets/logo.png`，同时用作 favicon
- 保存后**刷新页面依然生效**；「恢复默认」可一键还原

### 2.9.7 目录配置（v1.9）
五个目录可改：models / logs / data / templates / verification。
必须是容器内**存在的绝对路径**，改完需重启服务生效。

### 2.9.8 本地文件管理（v1.9）
一个内置的文件管理器，可以：

- 浏览目录（⬆ 上级 / 路径栏跳转）
- 查看文件内容（📄 查看）
- **在线编辑并保存**（文本文件，上限 2MB）
- 新建文件 / 新建目录
- 上传（支持多选）/ 下载
- 改名 / 删除

**安全边界**：只能访问 `/amm`、`/models`、日志与数据目录。
`/etc/passwd`、`../` 穿越、`/root` 都会被拒绝（403）。

**删除策略**：默认**移入回收站** `/amm/.trash`（可恢复），
在弹出的第二个对话框里确认才是永久删除。

> 这个管理器也当「目录选择器」用：目录配置里的 📂 按钮、LOGO 的 📂 按钮都复用它。

### 2.9.9 运维操作
- **🔄 重载配置**：重新读取 `models_config.yaml`
- **🔄 重启服务**：重启 AMM 进程（会中断所有推理，需确认）
- **📥 下载服务日志**：导出最近 500 行

### 2.9.10 推理引擎管理
- **🔄 刷新上游版本**：查询 llama.cpp GitHub Releases 与各引擎的 PyPI 版本
- 每个引擎显示已安装的版本，未安装的显示「下载 / 安装」
- 安装/卸载是异步任务，点任务可看实时进度与日志
- 已安装的可「卸载」（会删目录，正在运行的实例会失效，需确认）

## 2.10 常见操作速查

| 我想… | 怎么做 |
|---|---|
| 跑第一个模型 | Models → 选 Embedding + llama.cpp + 0.6B 模型 → 启动 |
| 让 Cherry Studio 用上 | 签一个虚拟 Key，客户端 base_url 填 `http://<IP>:<端口>/v1` |
| 看模型到底回了什么 | Log Center → 调用历史 → 展开某一行看「输出」 |
| 模型启动报错 | Dashboard 点模型名 → 看日志；或 Log Center 按模型过滤 |
| 换模型文件 | Dashboard 点模型名 → 更换模型文件 → 重启 |
| 磁盘满了 | Log Center → 清理；Tools → 检查模型文件占用 |
| 忘记 API Key | Settings 里点「复制」，或重新生成（旧的会失效） |
| 改界面名字和 LOGO | Settings → 项目品牌 |

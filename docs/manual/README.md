## 快速上手（3 分钟）

### 第 1 步：打开界面

浏览器访问 `http://<服务器IP>:<端口>/`（默认无需登录）。

### 第 2 步：确认环境正常

首页 Dashboard 应该能看到 CPU / 内存 / 磁盘 / GPU 都有数值。
如果全是 `--`，说明服务或接口有问题，见 [第 8 章](./08-故障排查.md)。

### 第 3 步：启动一个模型

进 **Models** 页 → 选模型类别（建议先试 **Embedding**）→ 引擎选 `llama.cpp`
→ 选模型文件 → **实例 UID 留空**（自动生成）→ 点 **▶ 启动**。

### 第 4 步：测试

进 **Playground** 页 → 选对应页签 → 选刚启动的模型 → 点测试按钮。

### 第 5 步：给客户端用

进 **Token Router** → 签发一个虚拟 Key（明文只显示一次，记得复制）
→ 客户端 base_url 填 `http://<服务器IP>:<端口>/v1`，API Key 填刚签的 Key。

> 详细步骤见 [第 2 章](./02-WebUI操作教程.md)。

## v1.9 新增功能速览

| 功能 | 位置 | 说明 |
|---|---|---|
| 项目品牌 | Settings → 项目品牌 | 改项目名 / 副标题 / LOGO，标题栏与 favicon 同步 |

| 调用历史增强 | Log Center → 调用历史 | 流式也记录真实输出，本地 embeddings/rerank 也记录 |
| launch 等就绪 | Models → 启动 | 返回时端口已可用，不再瞬时 500 |
| 日志轮转 | — | 自动 50MB × 5，不会写满磁盘 |
| API Debug | Playground → API | 在线调接口 |

## 技术规格

| 项 | 值 |
|---|---|
| 后端 | Python 3.11 + aiohttp |
| 前端 | 原生 JS（无框架），单页应用 |
| 数据库 | SQLite（实例定义）+ JSON（路由/配置） |
| 推理引擎 | llama.cpp / vLLM / Diffusers / sentence-transformers |
| API 兼容 | OpenAI（`/v1/chat/completions`、`/v1/embeddings` 等） |
| 部署 | Docker 容器（推荐）/ 裸机 |
| 版本 | v1.9 |

# AMM 界面白盒测试计划 (v0.5)

> 目标：覆盖 WebUI 所有页面、按钮、功能，验证前后端联动正确。
> 方式：白盒 + headless Chromium(CDP) 驱动真实页面自动化断言。

## 一、测试范围与覆盖矩阵

| 页面/模块 | 功能点 | 验证项 |
|-----------|--------|--------|
| **导航栏** | 6 个 Tab | dashboard/models/playground/logs/settings 可切换，无 GPU |
| **顶部** | 刷新间隔/主题/时钟/状态点 | 主题切换生效、刷新间隔选择生效、Online 状态 |
| **Dashboard** | 系统卡/GPU/Model共9卡 | CPU/Mem/Disk 数值填充；GPU 3+字段+运行程序；Model 3×3 布局 |
| **Models** | 引擎选择/文件浏览器/参数/预设 | 选择引擎刷新；浏览 /models 多级；预设发现；Save |

| **Logs** | 模型日志选择/刷新 | 选择模型→拉日志 |
| **Settings** | 服务配置/运维/引擎管理/下载/量化 | reload/restart/下载日志；引擎列表；下载面板；量化转换 |

| **API** | /api/health /v1/* | 全端点连通 |

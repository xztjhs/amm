## 关键经验
1. **venv 调用必须用绝对路径** `venv/bin/python3.11`（cd+裸 python 会命中系统 PATH 装到系统）
2. **vLLM 需要 HF safetensors 模型**（GGUF qwen35moe 不支持）；用 ModelScope 下 Qwen3-4B
3. **混合源安装**：`--index-url aliyun --extra-index-url https://download.pytorch.org/whl/cu130`（torch 从 cu130 源）
4. **vllm 安装网络绕坑**：numpy/个别包从国外 files.pythonhosted 下载超时 → 先用 aliyun 单独预装 numpy 到 venv，再装 vllm
5. **AI 桥接 bug 调试**：setup_routes 里 POST /v1/chat/completions 注册到 chat_completions_stream（非 chat_completions），改 stream 才对
6. **AMM 进程残留 bug**：vllm 含 VLLM::EngineCore 子进程，stop 不净需手动 kill -9（含 EngineCore），否则端口占、显存不释放
7. pending: pip 缓存 /root/.cache/pip ~9.6G 可清理（可选）
8. 验证顺序遵守显存铁律：每类只开1个串行

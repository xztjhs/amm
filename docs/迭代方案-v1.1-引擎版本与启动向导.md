## 1. 引擎版本从哪来

```
llama.cpp            GitHub Releases API  /repos/ggml-org/llama.cpp/releases
                     tag 形如 b12377 → 展示 b12377 (cuda) / b12377 (cpu)
vLLM                 PyPI JSON          https://pypi.org/pypi/vllm/json
Diffusers            PyPI JSON          https://pypi.org/pypi/diffusers/json
sentence-transformers PyPI JSON         https://pypi.org/pypi/sentence-transformers/json
```

- 结果缓存 30 分钟（`/amm/data/engine_catalog_cache.json`），离线时回退到内置预设清单，页面不会白屏。
- 安装状态=磁盘扫描 `$AMM_ENGINES_ROOT/<engine>/<version>-<flavor>/`，不再依赖 `installed.json` 的旧键。
- 安装方式三种：
  - `source-build`：llama.cpp，`git clone --branch <tag>` + cmake（cpu: `GGML_CUDA=OFF`；cuda: `GGML_CUDA=ON`）
  - `pip-venv`：vLLM / Diffusers / sentence-transformers，独立 venv，torch 走 cpu 或 cu130 index
  - 不支持 `tarball`：Ubuntu 预编译二进制依赖 glibc 2.39，Rocky 9 是 2.34，跑不起来（已在方案中排除）

## 2. 为什么必须区分 CPU / GPU

| 引擎 | cpu flavor | cuda flavor | 说明 |
|---|---|---|---|
| llama.cpp | ✅ | ✅ | 两套编译产物；CPU 版 `-ngl 0`，显存 0；GPU 被大模型占满时可回落 |
| sentence-transformers | ✅ | ✅ | cpu = torch cpu wheel（不占显存），cuda = torch cu130 |
| vLLM | ❌ | ✅ | 纯 GPU，无 CPU 后端 |
| Diffusers | ❌ | ✅ | 纯 GPU 推理 |

## 3. 统一启动向导（Launch Model / Running Models 共用）

```
① 模型类别 (chat/embedding/reranker/asr/tts/ocr/image/video)
      ↓ 过滤 supported_categories
② 推理引擎 (仅列出已安装且支持该类别的引擎)
      ↓
③ 版本 + flavor (来自 /api/engines/installed)
      ↓
④ 模型文件 (📂 浏览 /models，按引擎过滤扩展名)
      ↓
⑤ 参数表单 (GET /api/schema/params?category=&engine=，与 Models 页同一份定义)
      ↓
⑥ 启动 / 停止 (POST /api/instances/launch | /api/instances/{uid}/stop)
```

- 启动成功后实例落到 Running Models 表格；参数与引擎选择持久化（SQLite）。
- 可选「另存为模版」，把当前选择固化成 YAML。

## 4. 模版结构（扩展）

```yaml
id: qwen3-embedding-0.6b
name: Qwen3-Embedding-0.6B
category: embedding
description: ...
tags: [embedding, qwen3]
context_length: 32768
vram_hint_gb: 2
sources:
  - provider: huggingface
    repo_id: Qwen/Qwen3-Embedding-0.6B
engines:
  - engine: sentence_transformers
    version: "3.3.1"
    flavor: cuda
    params: { batch_size: 32, max_seq_length: 8192, normalize: true }
  - engine: llama_cpp
    version: latest
    flavor: cuda
    params: { ctx_size: 8192, n_gpu_layers: -1, embeddings: true }
model_file: ""
parameters:            # 完整参数定义（用于编辑表单回填）
  - { name: batch_size, label: 批大小, type: number, default: 32 }
```
